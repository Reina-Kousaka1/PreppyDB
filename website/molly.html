THE OFFICIAL MASCOT

Molly keeps
the vibes indexed.

PreppyDB began with “molly’s own db” and grew into a deliberately independent Rust database project. Molly is its official mascot—not a claim that the database needs a character, account, or production service to run.

“A good backup is like a good lip gloss: have it before you need it.”

Try the local playground for a decorative example, then return to the source docs for the real implementation details.
